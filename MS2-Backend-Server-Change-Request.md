# ClayMaster MS2 — Backend Requirements (Client Feedback)

**Source:** MS2 Initial Subscriber Usability Review 081126  
**For:** Backend team  

We used the client usability review doc to identify backend / server / content changes. These are items the mobile app cannot finish alone. Mobile handles UI separately.

---

## Must fix

1. **Video playback** — Client reports heavy buffering (e.g. Chandelle). Videos must play smoothly, including on weak / rural internet.

2. **Field Mode saved videos** — Save must allow real offline watching on the course, not only a link that still needs internet. *(Offline may be outside current milestone — PM confirming.)*

3. **Managed Services – Analytics** — Not purchase-only. User must request analytics, attach/send their scorecard, and have sessions consumed correctly.

4. **On-line Coaching bookings** — After booking, show the session under Upcoming and decrease the remaining session count.

---

## Also required

5. **Practice drills access** — Classic = 9 drills, Pro = 13. Enforce correct access per plan.

6. **Additional Videos** — Provide portal-style sub-categories so users can find content.

7. **Instructional Videos content** — Thumbnails plus groups: Target Presentations, ClayMaster Vision, Tournament Prep (Pro).

8. **Notifications** — Clarify/support how items reach the in-app bell (and push if in scope).

9. **About Us** — Keep team/content in sync with the website (include Bill McGuire).

10. **Community create post** — Create post must work, or return a clear error to the user.
